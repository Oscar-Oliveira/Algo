# 7. Problemas Reportados

Área: **Definições → Problemas Reportados**. Requer admin global.

Lista os problemas que os estudantes reportam a partir do editor (ex:
um erro inesperado, um comportamento estranho do Alguem). Cada relatório
mostra o email de quem reportou e a descrição escrita pelo estudante.

## 7.1 Contagem e "não vistos"

Dois indicadores no topo: total de relatórios e quantos ainda não foram
vistos. Um emblema (badge) na barra lateral do painel mostra o número
de relatórios não vistos, para chamar a atenção sem teres de abrir a
aba.

**Abrir esta aba marca automaticamente todos os relatórios como
vistos** — não é preciso nenhuma ação extra por relatório.

## 7.2 Apagar um relatório

Cada linha tem um botão para apagar esse relatório — física e
definitivamente. Útil depois de resolveres o problema reportado ou de
confirmares que não é acionável.

## 7.3 Paginação

A lista é paginada — usa "Anterior"/"Seguinte" para navegar quando há
muitos relatórios.
