Algo — ajuda

O que são o Algo e o Alguem?

Algo é uma linguagem algorítmica em português, concebida para ensinar programação e desenvolver o pensamento algorítmico. A sua sintaxe é deliberadamente simples e próxima do pseudocódigo, mas, ao contrário do pseudocódigo tradicional, os programas são executáveis. A linguagem exige a declaração explícita dos tipos de dados e possui uma gramática reduzida, procurando minimizar a complexidade sintática sem eliminar os conceitos fundamentais da programação.

Alguem é o tutor baseado num Modelo de Linguagem de Grande Escala (LLM) que acompanha o estudante durante a utilização do Algo. O seu objetivo não é resolver os exercícios, mas apoiar o processo de resolução. Pode colocar questões, fornecer pistas, explicar conceitos, ajudar a interpretar erros ou chamar a atenção para aspetos que merecem ser reconsiderados. A assistência é deliberadamente limitada para evitar que o estudante receba uma solução completa ou código pronto a copiar.

A secção Manual desta página constitui a referência da linguagem Algo. Aí são descritos a sintaxe, os tipos de dados, as estruturas de controlo e as restantes construções da linguagem, acompanhados de exemplos de utilização.

1. Introdução

ALGO é uma linguagem algorítmica: uma notação formal, mas próxima da linguagem natural em português, para descrever algoritmos de forma precisa o suficiente para serem executados. Nasceu para ensino de programação, e por isso os seus princípios de desenho são:

  • Tudo o que se escreve tem de ter um tipo explícito — nunca há inferência de tipos, para não haver ambiguidade sobre o que uma variável guarda
  • A gramática é pequena: poucas construções, cada uma a fazer uma coisa só
  • Os erros de tipo são detetados antes da execução (ver capítulo 17), não durante
  • Os índices de arrays começam em 0, os mesmos que a generalidade das linguagens de programação atuais

1.1 Um primeiro programa

algoritmo "Saudacao"

inicio
    nome:cadeia
    escrever("Como te chamas? ")
    ler(nome)
    escrever("Olá, ", nome, "!")

Um programa tem sempre um nome (entre aspas, depois de algoritmo) e um bloco inicio com as instruções a executar. Os blocos delimitam-se por indentação: cada nível é um tab OU um grupo de 4 espaços (nunca uma mistura dos dois na mesma linha).

Todas as palavras-chave da linguagem estão listadas por referência no Anexo B; aqui fica uma visão geral agrupada por função, para ires ganhando intuição antes dos capítulos detalhados:

2. Estrutura de um programa

algoritmo "NomeDoPrograma"

importar Math
incluir "outroficheiro.algo"

constante PI:decimal = 3.14159
total:inteiro = 0            // variável global

estrutura Ponto
    x:inteiro
    y:inteiro

funcao dobro(x:inteiro):inteiro
    devolver x * 2

inicio
    y:inteiro = dobro(5)     // variáveis locais: declara-se onde for preciso
    escrever(y)

Não existe uma zona fixa de "declaração de variáveis": uma variável declara-se onde for necessária, com a forma nome:tipo. As secções (importar, incluir, constantes/variáveis globais, estrutura, funcao/procedimento) podem aparecer em qualquer ordem antes do inicio, que é sempre o último bloco e o ponto de entrada do programa.

Nota: Só as variáveis declaradas fora de qualquer funcao/procedimento (antes ou dentro do inicio) são globais — visíveis e alteráveis a partir de qualquer função. As restantes são locais à função onde são declaradas.

3. Tipos de dados

Tipo Representa Exemplo de literal
inteiro números inteiros 42, -7, 0
decimal números com casas decimais 3.14, -0.5
booleano verdadeiro ou falso verdadeiro, falso
cadeia texto "Bom dia" (aspas duplas)
caracter um único símbolo 'a' (aspas simples)

Além destes cinco tipos primitivos, um programa pode definir os seus próprios tipos compostos com estrutura (capítulo 11). Não há conversões implícitas entre tipos: um decimal aceita um inteiro (promoção natural, sem perda de informação), mas o contrário não é automático.

4. Variáveis

4.1 Declaração

idade:inteiro                    // valor por omissão: 0
nome:cadeia = "Rita"             // com valor inicial
a, b, c:inteiro                  // três variáveis do mesmo tipo

Os valores por omissão de cada tipo, quando não se dá um valor inicial:

Tipo Valor por omissão
inteiro 0
decimal 0.0
booleano falso
cadeia ""
caracter ""

4.2 Atribuição

idade = 20

O sinal = é sempre atribuição. Para comparar dois valores usa-se == (capítulo 6).

4.3 Regras para nomes

  • Começam por uma letra ou underscore (_)
  • Podem conter letras, números e underscores
  • Não podem ser uma palavra reservada (ver Anexo B)
  • Os tipos primitivos e os nomes de bibliotecas (math, cadeia) não são palavras reservadas — podes ter uma variável chamada total mesmo que exista uma biblioteca com outro nome parecido

4.4 Âmbito (visibilidade)

Uma variável local (declarada dentro de uma função) só existe dentro dessa função. Uma variável global (declarada fora de qualquer função) é visível e alterável a partir de qualquer função do programa, sem ser preciso passá-la como parâmetro. Um parâmetro ou uma variável local pode ter o mesmo nome de uma global: dentro dessa função, o nome refere-se sempre à variável local (ela "sombreia" a global).

total:inteiro = 0

procedimento acumular(x:inteiro)
    total = total + x         // refere-se à global 'total'

inicio
    acumular(5)
    escrever(total)           // 5

5. Constantes

constante declara um valor que não pode voltar a ser alterado — nem por atribuição, nem por ler(), nem passado por ref. Tem sempre de ter um valor inicial, e não pode ser um array. Pode ser global ou local a uma função:

constante IVA:decimal = 1.23

funcao precoComIva(preco:decimal):decimal
    devolver preco * IVA

6. Operadores

Categoria Operadores Exemplo
Atribuição = x = 5
Igualdade / diferença ==   <> x == 5   x <> 5
Relacionais < > <= >= x < 10
Lógicos e ou nao (x > 0) e (x < 10)
Aritméticos + - * / div mod ^ 7 div 2 -> 3   7 mod 2 -> 1   2 ^ 3 -> 8

O operador + também concatena texto quando os dois lados são cadeia/caracter: 

escrever("Olá, " + nome + "!")

Nota: div e mod arredondam sempre em direção a zero (divisão truncada), não para baixo — -7 div 2 dá -3 (não -4), e -7 mod 2 dá -1 (o resto tem sempre o mesmo sinal que o primeiro operando).

Nota: Precedência, da maior para a menor: parênteses; potência ^; menos unário; * / div mod; + -; operadores relacionais; nao; e; ou. Na dúvida, usa parênteses — tornam o código mais claro.

7. Entrada e saída

escrever("O valor é: ", x, " e o dobro é: ", x * 2)
ler(x)

escrever aceita vários valores separados por vírgula, e escreve-os todos seguidos, sem espaços automáticos entre eles. ler() lê um valor do teclado e converte-o para o tipo declarado da variável.

8. Estruturas de decisão

8.1 se / entao / senao

se nota >= 18 entao
    escrever("Excelente")
senao se nota >= 10 entao
    escrever("Aprovado")
senao
    escrever("Reprovado")

Podem existir vários senao se em sequência; o senao final é opcional.

8.2 escolher / caso

escolher diaSemana
    caso 1
        escrever("Segunda-feira")
    caso 6, 7
        escrever("Fim de semana")
    contrario
        escrever("Dia útil")

9. Ciclos

9.1 para — número de repetições conhecido

A variável de controlo tem de estar declarada antes do ciclo, tal como qualquer outra variável — o para não a declara por si. E só existe dentro do corpo do ciclo: usá-la depois de o ciclo terminar é um erro de compilação.

i:inteiro
para i de 0 ate 9 fazer
    escrever(i)

para i de 10 ate 1 passo -1 fazer
    escrever(i)

9.2 enquanto — verifica a condição antes

enquanto saldo > 0 fazer
    saldo = saldo - mensalidade

9.3 fazer ... enquanto — verifica a condição depois

fazer
    ler(opcao)
enquanto opcao <> 0

Nota: O corpo do fazer...enquanto executa sempre pelo menos uma vez, ao contrário do enquanto.

10. Arrays

Um array guarda vários valores do mesmo tipo, acedidos por índice. Os índices começam em 0 (tal como em Python, Java, C, C#...): um array de tamanho N tem posições válidas de 0 a N-1. Suporta-se qualquer número de dimensões:

notas:decimal[30]                // vetor de 30 posições: notas[0] .. notas[29]
tabuleiro:inteiro[8][8]          // matriz
cubo:inteiro[3][3][3]            // 3 dimensões -- ou mais, se precisares

i:inteiro
para i de 0 ate 29 fazer
    soma = soma + notas[i]

Um array pode ser inicializado com uma lista de valores entre { }:

primos:inteiro[5] = {2, 3, 5, 7, 11}
tabuleiro:inteiro[2][2] = {{1, 2}, {3, 4}}

11. Estruturas (registos)

estrutura agrupa vários campos com nome sob um único tipo. Os campos acedem-se com .:

estrutura Ponto
    x:inteiro
    y:inteiro

estrutura Retangulo
    canto:Ponto            // uma estrutura pode conter outra
    largura:inteiro
    altura:inteiro

inicio
    p1:Ponto
    p1.x = 3
    p1.y = 4

    pontos:Ponto[10]       // array de estruturas: cada posição é independente
    pontos[0].x = 100

Também é possível inicializar com um literal { campo: valor, ... } — campos omitidos ficam com o valor por omissão do seu tipo:

p1:Ponto = {x: 3, y: 4}
p2:Ponto = {x: 10}          // y fica 0

12. Funções e procedimentos

Uma função devolve um valor (com devolver); um procedimento não devolve nada, serve para executar uma ação. Os parâmetros usam sempre a forma nome:tipo, e podem ser passados por valor (por omissão — o parâmetro recebe uma cópia) ou por referência (ref — o parâmetro partilha a variável do chamador, e alterações dentro da função são visíveis fora dela). ref pode ser usado tanto em funções como em procedimentos.

procedimento trocar(ref a:inteiro, ref b:inteiro)
    temp:inteiro = a
    a = b
    b = temp

funcao incrementar(ref x:inteiro):inteiro
    x = x + 1
    devolver x

inicio
    p:inteiro = 3
    q:inteiro = 9
    trocar(p, q)                    // p passa a 9, q passa a 3
    novo:inteiro = incrementar(p)   // p também é alterado; novo recebe o valor devolvido

Nota: Uma chamada com parâmetros ref só pode ser usada como instrução isolada, ou diretamente à direita de uma atribuição (x = f(...)) — nunca dentro de outra expressão maior, porque precisa de atualizar as variáveis originais depois de a função terminar.

12.1 Recursividade

funcao fibonacci(n:inteiro):inteiro
    se n <= 1 entao
        devolver n
    senao
        devolver fibonacci(n - 1) + fibonacci(n - 2)

Uma função pode chamar-se a si própria. Não há limite explícito na linguagem, mas a recursão infinita é sempre um erro de lógica do programa.

13. Bibliotecas

As funções auxiliares da linguagem estão agrupadas em bibliotecas com namespace — math.raiz(x), cadeia.comprimento(s). É preciso importar a biblioteca antes de a usar: 

importar Math
importar Cadeia

inicio
    escrever(math.raiz(16.0))          // 4.0
    escrever(cadeia.maiusculas("ola")) // OLA

13.1 Math

Função Descrição
math.raiz(x) raiz quadrada
math.potencia(b, e) b elevado a e
math.absoluto(x) valor absoluto
math.piso(x) arredonda por baixo
math.teto(x) arredonda por cima
math.aleatorio(a, b) inteiro aleatório entre a e b

13.2 Cadeia

Função Descrição
cadeia.comprimento(s) número de caracteres
cadeia.maiusculas(s) converte para maiúsculas
cadeia.minusculas(s) converte para minúsculas
cadeia.inverter(s) inverte a cadeia
cadeia.subcadeia(s, ini, fim) sub-cadeia entre índices (0-baseado; fim exclusivo)
cadeia.caracter(s, i) o caracter na posição i (0-baseado, tal como os arrays)

14. incluir — múltiplos ficheiros

incluir "caminho/ficheiro.algo" junta as funções, procedimentos, estruturas e variáveis globais desse ficheiro ao programa, sem namespace. O ficheiro incluído contém só declarações e funcao/procedimento/estrutura — não tem cabeçalho algoritmo nem bloco inicio.

// geometria.algo
funcao areaCirculo(raio:decimal):decimal
    pi:decimal = 3.14159
    devolver pi * raio * raio
// principal.algo
algoritmo "Principal"
incluir "geometria.algo"

inicio
    escrever(areaCirculo(3.0))

16. afirmar

afirmar verifica uma condição; se for falsa, o programa para e mostra uma mensagem. É a forma que a linguagem dá para um programa se autovalidar, sem precisar de um enquadramento de testes à parte:

funcao dobro(x:inteiro):inteiro
    devolver x * 2

inicio
    afirmar dobro(5) == 10, "dobro(5) devia ser 10"
    escrever("passou no teste")

Se a condição for verdadeira, afirmar não produz nenhuma saída. A mensagem, depois da vírgula, é opcional.

17. Verificação de tipos

Todo o programa ALGO é verificado antes de correr: a linguagem exige que os tipos batam certo em todo o lado — atribuições, condições, argumentos de funções, índices de arrays. Isto é uma propriedade da própria linguagem (não uma ferramenta à parte): um programa com um erro de tipo simplesmente não é um programa ALGO válido. Exemplos do que não é permitido:

  • Atribuir um valor de um tipo a uma variável de outro tipo incompatível
  • Uma condição de se/enquanto que não seja booleano
  • Os limites de um ciclo para que não sejam inteiro
  • Chamar uma função com o número ou tipo de argumentos errado
  • Um índice de array que não seja inteiro
  • Usar uma variável que nunca foi declarada
  • Alterar uma constante

18. Os três tipos de erro de compilação

Uma mensagem de erro do ALGO começa sempre por dizer QUE TIPO de erro é -- "Erro léxico", "Erro de sintaxe" ou "Erro semântico". Não é preciso saber a diferença para corrigir o erro (a mensagem já diz o que fazer), mas ajuda a perceber porque é que erros parecidos podem ser reportados de formas diferentes:

  • Léxico — o problema está nos próprios símbolos do texto, antes de a linguagem sequer tentar perceber a estrutura da frase. Ex: um caracter entre aspas simples com mais do que um símbolo, ou um número mal escrito.
  • Sintático (de sintaxe) — os símbolos existem, mas não estão na ORDEM que a gramática do ALGO espera. Ex: esqueceres o entao a seguir a um se, ou fechares um bloco a menos.
  • Semântico — a frase está bem formada (compreensível gramaticalmente), mas não faz sentido dado o que já foi declarado antes. Ex: usar uma variável nunca declarada, ou tentar somar um booleano com um inteiro (ver secção 17).

É por esta ordem que o compilador procura erros: primeiro léxico, depois sintático, só depois semântico -- por isso nunca vês um erro semântico enquanto ainda houver um erro léxico ou de sintaxe por corrigir antes.

Anexo B — Palavras reservadas

algoritmo, inicio, estrutura, escrever, ler, se, entao, senao, para, de, ate, passo, fazer, enquanto, escolher, caso, contrario, funcao, procedimento, devolver, ref, importar, incluir, constante, afirmar, verdadeiro, falso, e, ou, nao, div, mod.
